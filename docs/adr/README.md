# Bản ghi quyết định kiến trúc (ADR)

Mỗi ADR ghi lại một quyết định kỹ thuật có ảnh hưởng lâu dài: bối cảnh, phương án đã xét, lựa chọn và hệ quả. Khi một quyết định thay đổi, nhóm viết ADR mới và đổi trạng thái ADR cũ thành "Bị thay thế bởi ADR xxxx". Không sửa nội dung ADR đã chấp nhận.

| Số | Tiêu đề | Trạng thái |
|---|---|---|
| [0001](0001-moi-truong-mo-phong.md) | Dùng RoboTwin với mô hình Panthera-HT làm môi trường mô phỏng | Chấp nhận |
| [0002](0002-vla-dau-cuoi.md) | Mô hình VLA đầu-cuối là hệ thống chính | Chấp nhận |
| [0003](0003-nguon-du-lieu.md) | Sinh dữ liệu bằng chuyên gia mô phỏng và mô hình ngôn ngữ | Chấp nhận |
| [0004](0004-lop-an-toan.md) | Lớp an toàn bắt buộc giữa mô hình và robot thật | Chấp nhận |
| [0005](0005-lua-chon-mo-hinh-vla.md) | Chọn mô hình VLA nền | Đang xem xét |

Mẫu cho ADR mới: sao chép một file có sẵn, giữ các mục Bối cảnh, Phương án, Quyết định, Hệ quả.
