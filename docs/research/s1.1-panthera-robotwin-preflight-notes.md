## Vendor Panthera environment documented at inspected commit

The Panthera README recommends Linux + NVIDIA GPU + Conda + working Vulkan and documents a Panthera simulation/data-collection environment with:
- Python 3.10.20;
- PyTorch 2.7.1 + CUDA 12.8;
- SAPIEN 3.0.0b1;
- MPlib 0.2.1;
- CuRobo 0.7.8;
- NumPy 1.26.4 and other pinned dependencies.

The README explicitly warns that:
- `nvidia-smi`'s displayed CUDA version is only the driver compatibility ceiling, not the local `nvcc` version;
- CuRobo's compiled CUDA extension requires `nvcc` to match the PyTorch CUDA 12.8 build;
- Panthera's CuRobo integration currently expects an editable checkout under `RoboTwin/envs/curobo`;
- the upstream RoboTwin `script/_install.sh` should not be blindly used as the complete Panthera install procedure because its versions differ from the Panthera-validated set.

The vendor README pins CuRobo v0.7.8 to:
`d64c4b005459db10c5dd867d8b30a87d5bda9bdb`.

## Lowest-complexity single-arm smoke candidate

The inspected vendor repo contains:
`task_config/move_pillbottle_pad_panthera_single.yml`.

Relevant settings:
- `arm_mode: single`;
- one `panthera-6dof` embodiment;
- RGB enabled;
- head camera enabled (D435 profile);
- wrist camera enabled (D405 profile);
- depth disabled;
- point cloud disabled;
- end pose + qpos enabled;
- video logging enabled.

Vendor-supported CLI allows overriding episode count and save root, so the intended first smoke is one episode only:

```bash
python -u script/collect_data.py \
  move_pillbottle_pad \
  move_pillbottle_pad_panthera_single \
  --episode-num 1 \
  --save-path <dedicated-smoke-output>
```

The vendor README reports that single-arm Panthera data use a native 7-D action representation: six arm joints plus one gripper value.

## Installation details that W-A must independently review

Before the first Ubuntu boot/install task is finalized, W-A must specifically assess:
1. whether PyTorch 2.7.1 + cu128 and the required CUDA 12.8 compiler path are viable on GTX 1660 Ti Max-Q (Turing, 6 GB);
2. CuRobo v0.7.8 build/runtime feasibility under the 6 GB VRAM budget;
3. Vulkan/SAPIEN support for this GPU/driver family;
4. whether the vendor's clean-room environment needs modification for Ubuntu 22.04 in this exact hardware context;
5. the smallest camera/render configuration if two RGB cameras + CuRobo exceed memory;
6. whether Open3D import overhead can remain acceptable (vendor notes the camera module imports it even when point-cloud output is disabled).
